# Suma de Dos Elementos - Pigmalion

## Descripción

Este proyecto contiene la solución al ejercicio solicitado por Pigmalion.  
El programa recibe una lista de números enteros y una suma requerida, y determina si existen dos números que sumen ese valor.

## Lenguaje y Herramientas utilizadas

- Lenguaje: C#  
- Versión de .NET utilizada: .NET 9.0.100 
- Editor: Visual Studio / Visual Studio Code  

## Cómo usar

1. Clonar el repositorio o descargar el código fuente.  
2. Abrir la solución en el editor de su preferencia.  

### En Visual Studio:
- Abrir el archivo `.sln`.
- Seleccionar el proyecto deseado (**punto1_recursosInfinitos** o **punto2_recursosLimitados**).
- Ejecutar.
